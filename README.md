A web-based guide to exploring the United States through a state-by-state tour map. Users can browse through information regarding each state to discover popular landmarks, cultural highlights, and top-rated restaurants.

![homepage](https://github.com/user-attachments/assets/cce1debc-9dad-4029-bc45-811e80c121d5)

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app). 

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
